New page focusing on Communities near Austin. Aug 17, 2007.


We should contact these places ahead of time to:

  • make sure they're cool with visitors
  • find out how long we can stay
  • find out how much notice they need when we're coming
  • find out if we'll have to pay, or if we can barter for room/board, or if there's anything they need we might be able to acquire


Other community resources:

  • Directory of Intentional Communities at the FIC (organized geographically)
  • Global Ecovillage Network
  • federation of egalitarian communities
